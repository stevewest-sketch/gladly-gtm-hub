EXERCISE 3

Building Guides

Guides are multi-step workflows that help Sidekick handle complex conversations. They define how to gather info, take actions, and escalate when needed.

  • Steps: Define the conversation flow
  • Actions: Connect to external systems
  • Transfers: Set escalation conditions
  • Guardrails: Define what Sidekick should NOT do

Try It Now

1

Go to Sidekick > Guides and click "Create Guide"

2

Name your Guide (e.g., "Order Status Inquiry")

3

Add steps: Greet > Collect order # > Look up > Respond

4

Define when to transfer to a human agent
